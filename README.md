# 🧠 QuizNova – Java Quiz Application

Simple Minds is a desktop-based Quiz Application developed using **Java and Java Swing**. It provides an interactive quiz experience where users can answer multiple-choice questions within a limited time, use lifelines, and view their final scores.

The application features a simple and user-friendly graphical interface with multiple screens, including Login, Rules, Quiz, and Score.

## 🚀 Features

- **User Login:** Enter your name to start the quiz.
- **Instructions & Rules:** Read quiz instructions before starting.
- **Timed Quiz:** Answer questions within a limited time.
- **Multiple-Choice Questions:** Select answers from four available options.
- **Next Button:** Navigate through quiz questions.
- **50-50 Lifeline:** Eliminate two incorrect options to make answering easier.
- **Score Calculation:** View your final score after completing the quiz.
- **Play Again:** Restart the quiz and try to improve your score.
- **Interactive GUI:** Built with Java Swing for a desktop-based experience.

## 🛠️ Technologies Used

- Java
- Java Swing (GUI)
- AWT (Abstract Window Toolkit)
- Java Development Kit (JDK)
- VS Code

## 🎮 How to Play

1. Launch the application.
2. Enter your name on the Login screen.
3. Click the Rules button to read the instructions.
4. Click Start to begin the quiz.
5. Select an answer for each question.
6. Use the Next button to move forward.
7. Use the 50-50 Lifeline when needed.
8. Submit your answers to view your final score.
9. Click Play Again to restart the quiz.
