# QuizNova – Java Quiz Application

QuizNova is a Java-based quiz application designed to provide an interactive platform for attempting quizzes and testing knowledge. The project demonstrates the use of Java programming concepts and application development.

## Features

- Java-based quiz application
- Interactive quiz interface
- Quiz-based question and answer functionality
- Simple and user-friendly application structure

## Technologies Used

- **Programming Language:** Java
- **IDE:** NetBeans
- **Build Tool:** Apache Ant
